# TinyRack Homebrew Tap

**Official Homebrew tap for TinyRack CLI tools.**

[Dotweave](https://github.com/tinyrack-net/dotweave) · [Documentation](https://dotweave.tinyrack.net/en/)

</div>

---

This repository provides Homebrew formulae for TinyRack projects.

## Usage

Add the tap once, then install a package from it:

```bash
brew tap tinyrack-net/tap
brew install dotweave
```

You can also install directly without adding the tap first:

```bash
brew install tinyrack-net/tap/dotweave
```

## Development

Formulae live under `Formula/`. When updating a formula manually, verify the release asset URLs and SHA-256 checksums before committing.
